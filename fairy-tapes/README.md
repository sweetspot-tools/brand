# Fairy Tapes logo

A mixtape: a line-drawn cassette with "Fairy Tapes" hand-written on a strip of masking tape as its label, and in the
window one reel and an amber sparkle in place of the other. The tape and the handwriting are the ones of the Fairy Tapes
panels (the tape is drawn as in the Sweetspot Tools logo). Every file is paths only: no font is needed.
The files are generated by `tools/gen_logo.py`; do not edit them by hand.

## Files

| File | Use |
|---|---|
| `fairy-tapes-logo-dark.svg` | horizontal logo (mixtape and wordmark) for dark backgrounds, transparent |
| `fairy-tapes-logo-light.svg` | horizontal logo for light backgrounds, transparent (the tape gets a thin edge) |
| `fairy-tapes-logo-mono-black.svg`, `-mono-white.svg` | one-colour logo (print, stamps, photographic backgrounds): the tape becomes an outline |
| `fairy-tapes-mark-*.svg` | the mixtape alone, in the same four variants |
| `fairy-tapes-avatar.svg`, `.png` | square avatar, 512 x 512, on the panel colour |
| `favicon.svg`, `favicon.ico` | site icon: the label becomes a blank strip of tape, the reel a dot; in the ICO the 16 px image is drawn on the pixel grid, 32 and 48 px come from the SVG |

## Colours

- Panel `#161617`, lines and wordmark `#c9c9c2` (the grey of "FAIRY TAPES" on the plug-in panels), sparkle `#f0b429`
  (the amber of a lit button face), tape `#e6dab6` with fibres `#d2c59e`, ink on the tape `#1d1d1e`.
- On light backgrounds: lines, wordmark and ink `#161617`, sparkle `#d99a00` (a deeper amber: `#f0b429` reads poorly
  on white), tape edge `#b9ab82`.

## Fonts

All converted to outlines; no font file is part of this repository.

| Text | Font | License | Source |
|---|---|---|---|
| label "Fairy Tapes" | Rock Salt (Font Diner / Sideshow) | Apache License 2.0 (`tools/LICENSE-RockSalt-Apache-2.0.txt`) | outlines of the label's characters in `tools/rocksalt_glyphs.json`, copied by `tools/extract_glyphs.py` from `shared/ui/include/fairy_ui/tape_glyphs.h` of the Fairy Tapes repository (generated there from https://github.com/google/fonts/blob/main/apache/rocksalt/RockSalt-Regular.ttf) |
| "FAIRY TAPES" | Liberation Sans Bold | SIL Open Font License 1.1 | system package (`/usr/share/fonts/liberation/`) |

The wordmark is upper case, spaced 0.16 em, as on the panels.

## Regenerate

Needs fontTools, Pillow, `rsvg-convert` and Liberation Sans in `/usr/share/fonts/liberation/`. From the repository root:

```bash
python3 fairy-tapes/tools/gen_logo.py
python3 -m pytest fairy-tapes/tools/test_gen_logo.py
```

Only if the label text changes, copy its glyphs again from a Fairy Tapes checkout first:

```bash
python3 fairy-tapes/tools/extract_glyphs.py /path/to/fairy-tapes/shared/ui/include/fairy_ui/tape_glyphs.h
```
