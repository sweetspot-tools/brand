# Fairy Tapes logo

A line-drawn cassette where one of the two reels is an amber sparkle. Every file is paths only: no font is needed.
The files are generated by `tools/gen_logo.py`; do not edit them by hand.

## Files

| File | Use |
|---|---|
| `fairy-tapes-logo-dark.svg` | horizontal logo (cassette and wordmark) for dark backgrounds, transparent |
| `fairy-tapes-logo-light.svg` | horizontal logo for light backgrounds, transparent |
| `fairy-tapes-logo-mono-black.svg`, `-mono-white.svg` | one-colour logo (print, stamps, photographic backgrounds) |
| `fairy-tapes-mark-*.svg` | the cassette alone, in the same four variants |
| `fairy-tapes-avatar.svg`, `.png` | square avatar, 512 x 512, on the panel colour |
| `favicon.svg`, `favicon.ico` | site icon; in the ICO the 16 px image is a simplified drawing (no window, no head opening), 32 and 48 px come from the SVG |

## Colours

- Panel `#161617`, lines and wordmark `#c9c9c2` (the grey of "FAIRY TAPES" on the plug-in panels), sparkle `#f0b429`
  (the amber of a lit button face).
- On light backgrounds: lines and wordmark `#161617`, sparkle `#d99a00` (a deeper amber: `#f0b429` reads poorly on
  white).

Wordmark "FAIRY TAPES": Liberation Sans Bold (SIL Open Font License 1.1) converted to outlines, upper case, spaced
0.16 em as on the panels.

## Regenerate

Needs fontTools, Pillow, `rsvg-convert` and Liberation Sans in `/usr/share/fonts/liberation/`. From the repository root:

```bash
python3 fairy-tapes/tools/gen_logo.py
python3 -m pytest fairy-tapes/tools/test_gen_logo.py
```
