# Sweetspot Tools logo

A torn strip of masking tape with "don't touch! it's the sweet spot" written in marker, and an amber arrow that lands on
the dot after the wordmark: the note you stick on a desk to keep a setting where it sounds right. The tape and the
handwriting are the ones of the Fairy Tapes panels. Every file is paths only: no font is needed.
The files are generated by `tools/gen_logo.py`; do not edit them by hand.

## Files

| File | Use |
|---|---|
| `sweetspot-tools-logo-dark.svg` | horizontal logo (tape, wordmark, arrow and dot) for dark backgrounds, transparent |
| `sweetspot-tools-logo-light.svg` | horizontal logo for light backgrounds, transparent (the tape gets a thin edge) |
| `sweetspot-tools-logo-mono-black.svg`, `-mono-white.svg` | one-colour logo (print, stamps, photographic backgrounds): the tape becomes an outline |
| `sweetspot-tools-mark-*.svg` | the logo without the wordmark (tape, arrow and dot), in the same four variants |
| `sweetspot-tools-avatar.svg`, `.png` | square avatar, 512 x 512: a close-up of a rack panel (grain, scratches, two screws), an aluminium knob as on The Stripper with its printed scale, the "don't touch!" tape stuck next to it and the amber arrow pointing at the marker dot where the knob is set |
| `favicon.svg`, `favicon.ico` | site icon: the avatar scene reduced to a strip of tape, the knob with its pointer and the marker dot; the knob is a little lighter so it does not vanish; in the ICO the 16 px image is drawn on the pixel grid, 32 and 48 px come from the SVG |

## Colours

- Panel `#161617`, wordmark `#c9c9c2`, marker `#f0b429` (the same grey and amber as Fairy Tapes), tape `#e6dab6`,
  ink on the tape `#1d1d1e`.
- On light backgrounds: wordmark and ink `#161617`, marker `#d99a00` (a deeper amber: `#f0b429` reads poorly on white),
  tape edge `#b9ab82`.
- Avatar: panel grain `#1f1f21` and `#0e0e0f`, scratches `#34343a`, knob and screws with the colours of
  `stripper_rack.html` (cap `#232427`, skirt `#0e0e0f`, pointer inlay `#d4d1c5`), scale `#c9c9c2`.

## Regenerate

Needs fontTools, Pillow, `rsvg-convert`, Liberation Sans in `/usr/share/fonts/liberation/` and a folder with
Homemade Apple. From the repository root:

```bash
python3 sweetspot-tools/tools/gen_logo.py --fonts /path/to/fonts sweetspot-tools
SWEETSPOT_FONTS=/path/to/fonts python3 -m pytest sweetspot-tools/tools/test_gen_logo.py
```
